# Donut Flip Scanner

Fabric mod for DonutSMP auction monitoring and profitable flip detection.

## Features

- Automatic auction house monitoring
- Accurate item recognition
- Market analysis
- Profitable flip detection

## Requirements

- Minecraft 1.20.4
- Fabric Loader 0.14.0 or higher
- Fabric API

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/donut-flip-scanner/releases).
2. Place the mod in your `mods` folder.
3. Launch Minecraft with Fabric.

## Usage

1. Launch Minecraft with the mod installed.
2. The mod will automatically monitor the auction house.
3. Use the trading dashboard to view profitable flips.

## Configuration

The mod can be configured by editing the `config.json` file in the mod's config directory. The configuration options include:

- `whitelist`: A list of item IDs to whitelist.
- `blacklist`: A list of item IDs to blacklist.
- `mockMode`: A boolean to enable or disable mock mode.
